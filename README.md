# Projeto-Integrador-IV
Dashboard interativo em Power BI desenvolvido para a CPTM, com dados extraídos e tratados do ERP ALVO via ETL. A solução oferece visão gerencial do estoque, indicadores de giro, cobertura, Curva ABC e alertas de ruptura/excesso, apoiando decisões logísticas mais rápidas e baseadas em dados.
